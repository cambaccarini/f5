# ⚽ Football Match Organizer App

Mobile application built with React Native (Expo) to organize football matches.

## 📌 Description

F5 is a mobile app that allows users to:
- Create football matches
- Define how many players are needed
- Join available matches
- Manage player participation

The goal of the app is to simplify the organization of casual football games between players.

## 🚀 Tech Stack

- React Native (Expo)
- TypeScript
- Component-based architecture

## 📱 Features

- Create new matches
- Join existing matches
- Define number of players per match
- View match details
